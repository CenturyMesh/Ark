## LinkedIn — Portuguese

Abri o código do ARK: um workspace CAD paramétrico para pessoas e agentes de IA,
disponível para Windows e Linux, sob licença Apache-2.0.

O ARK usa C++ e Open CASCADE para criar peças editáveis, assemblies e geometria
B-rep. Pessoas e agentes usam os mesmos comandos, histórico e controlo de revisões.
Inclui sketches, sólidos/superfícies, materiais, BOM e ferramentas MCP.

O Windows tem a aplicação gráfica Studio. O Linux tem, nesta fase, CLI, servidor
MCP e worker de geometria, sem interface gráfica. Há pacotes prontos a descarregar,
sem precisar de compilar. O uso CAD manual não exige uma conta de IA.

É uma primeira versão pública em desenvolvimento. Quero perceber onde a
experiência de criar, editar e guardar a primeira peça ainda precisa de melhorar.
Há um pequeno guia e um formulário de feedback no repositório.

Código, downloads e demonstração: https://github.com/CenturyMesh/Ark

## LinkedIn — English

ARK is now open source: parametric CAD for humans and AI agents, for Windows and
Linux, licensed under Apache-2.0.

Built with C++ and Open CASCADE, ARK combines editable CAD history, exact B-rep
geometry, assemblies, materials, BOM metadata and MCP tools. People and agents
work through the same modeling commands and revision checks.

Windows includes the graphical Studio. Linux currently provides the headless
CLI, MCP server and geometry worker. Ready-to-run packages are available; manual
CAD editing does not require an AI account.

This is an early public release. I am interested in concrete first-use feedback:
where does downloading, editing a first part, or saving and reopening become
confusing? A short walkthrough and feedback form are linked in the repository.

Source, downloads and demonstration: https://github.com/CenturyMesh/Ark

Suggested first comment, to be adapted and posted by the project owner:

I am building ARK, a C++/Open CASCADE CAD workspace where manual editing and AI
agents use the same document commands, editable history and revision checks.
I wanted a design workflow where you can inspect and keep editing what an agent
creates, including its part metadata and BOM.

The code is Apache-2.0. There are downloadable Windows and Linux x64 packages.
Windows has the native Studio UI; Linux is currently headless CLI/MCP/OCCT worker.
Manual editing does not require an AI account. Optional assistants use an
explicitly configured account/API/local-model route; external clients can connect
through MCP.

This is an engineering prototype, not a claim of CAD-suite parity or manufacturing
qualification. I would especially appreciate feedback on the first-part workflow,
document recovery, and whether the agent/CAD boundary is understandable.
