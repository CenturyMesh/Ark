# Support ARK

Support development through [CenturyMesh on GitHub Sponsors](https://github.com/sponsors/CenturyMesh).
The Sponsors listing was confirmed active on 12 October 2026 after the owner
completed onboarding. `.github/FUNDING.yml` enables the repository Sponsor button.

## Maintainer reference: account setup

The account owner must complete the financial and identity steps directly:

1. Open [GitHub Sponsors account setup](https://github.com/sponsors/accounts) while
   signed into the account authorized to manage `CenturyMesh`.
2. Follow the relevant account/organization onboarding flow and verify eligibility.
3. Complete the requested profile, identity, payout and tax information and required
   two-factor authentication. Submit private financial details only through GitHub's
   authenticated setup, never in a repository issue, document or agent chat.
4. Complete GitHub's review and confirm the public sponsor profile is live.
5. Choose whether to offer one-time or recurring support, with only explicitly
   approved terms. No tiers, benefits, rewards or service commitments are promised
   by this document.

See GitHub's official [organization setup guide](https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-organization)
and [personal account guide](https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-personal-account).
The owner must select the appropriate route and provide the actual details.

## Repository button

The active `.github/FUNDING.yml` contains:

```yaml
github: [CenturyMesh]
```

Check the resulting repository Sponsor button and its destination while signed
out. If onboarding uses a different approved account, use its exact live handle
instead. Do not point a funding file at an unpublished profile.

An alternative is an owner-approved external donation page. After verifying the
actual payment destination, use GitHub's `custom` funding field with that URL.
No provider, account or payment URL is inferred here. GitHub documents the
[funding-file configuration](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository).

Sponsorship does not change ARK's Apache-2.0 source license or provide an Enterprise
edition, paid support entitlement, feature deadline or manufacturing certification.
Any future commercial service needs separate explicit terms.
