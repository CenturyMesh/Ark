# 057B — conversation layout and viewport controls

Technical version **0.9.58**, sourced from `release.json`. Milestones:
**A.02/A.04/B.01/D.02**. Status: **Em curso** pending the local native build,
interaction checks and inspection of synthetic-fixture captures.

## Scope

Correct the visible conversation layout, especially the end of long replies,
while retaining native selection, Unicode, scroll position and the pinned goal.
Refine the orientation cube and consolidate the viewport display controls into
a readable toolbar with explicit modes and grouped overlays/navigation actions.

This iteration follows the locally integrated 056C runtime. Document geometry,
document format and agent completion/permission contracts are unchanged. The
validation uses synthetic fixtures, without user drawings or conversations.

## Evidence

Verification is in progress. The strengthened chat check requires the final
line of a long response to be visible after Latest; retaining the full string
alone is insufficient. Build logs and captures are local under
`out/057b-native/ui-checks` and `out/057b-*.log`.

Local runtime delivery is separate from installer/OTA publication. Broader
milestones remain **Parcial**; this work does not claim general project-size,
provider reliability or hardware-independent graphics qualification.
