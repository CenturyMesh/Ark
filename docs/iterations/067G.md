## Integrity and persistence

- Native B-rep remains geometry authority. Thumbnails and overlays are derived presentation only.
- Saved variants retain program-source hashes and explicit numeric configurations. Source changes require review; stale revisions and candidates reject without rebasing.
- New variant/tolerance data uses document semantics 56. Documents without those fields retain their existing conditional semantic version; the application iteration alone does not change a drawing format.
- Repairs cannot delete/suppress bodies, relax tolerances or substitute references silently. A failed correction leaves the valid current document unchanged.
- Team-owned previews undergo the same role-scope checks as ordinary commands. The single catalogue has 124 tools; the tested ParametricDesigner provider catalogue has 117, or 44 after its topic deferral, within the 128-function limit.
- Source-file digest checks bind library preparation to the catalog selection. PDFs publish atomically to new paths and reject stale sheets as a whole set.

### Failures found and resolved

The initial native run passed 179/182: two tests still treated semantic version 56 as a future format, and new onboarding topics omitted the drawing-authorization policy. All were corrected and the complete suite passed.

Initial modeless-window tests stalled because a continuously repainted native control could starve the worker completion check inside an unbounded message drain. The worker loops now drain bounded message batches, clear deferred internal paints and invalidate visible controls after work. The new windows then passed in approximately 1–2 seconds; existing asynchronous authoring and realtime tests also passed. This bounds UI event handling, not agent turns or tokens.

Visual review corrected thumbnail painter ordering, tolerance-frame leaders/text sizing and revision-report labels. A named variant save preserves staged values for subsequent Apply.

A pre-delivery ZIP was rejected before any installer or publication because its Studio compilation had started before the final staged-value preservation edit. It was retained outside the delivery folder as a rejected artifact; Studio was rebuilt from frozen source and the explicit staged-save assertion was checked in the rebuilt executable before repeating the affected suites.

## Limits

- Alternative generation uses the same callable contracts available to agents; model-provider quality, economic savings and autonomous design acceptance are not established by scripted tests.
- Exploration is a bounded explicit grid, not global or continuous optimization. It measures terminal program definitions, not union volume or multiplied assembly quantities. Mass requires declared densities; stiffness, FEA, fatigue and manufacturing qualification remain separate.
- Clearance is static at evaluated positions, not a continuous-motion certificate. Every failed attempt remains part of the result.
- Revision review covers retained local history, not distributed multi-user collaboration or archived/external revision retrieval. Overlays are visual comparisons, not exact Boolean difference solids.
- Tolerance frames are named authored requirements, not a certified ISO/ASME symbol/datum/metrology system. PDF uses existing derived drawing samples; exact DXF retains its separate contract. PDF labels are Latin-1; unsupported scripts reject explicitly.
- Only the affected ten Studio suites were rerun here; this does not claim that every historical Studio failure was repaired.
- Clean-machine qualification, Authenticode signing, hosted publication and online-update transport are not established by local installer checks. User drawings, sessions and installed application registration are outside test fixtures.
