## Correct context reuse

The authoring stamp uses length-prefixed fields, named section counts and the
same full-precision numeric encoding as saved source. A density change from
1.0000001 to 1.0000002 must rebuild the graph, including when an in-place edit
does not change the session revision. Canvas opacity has the same requirement.
Unchanged authoring reuses the graph and source hash without serializing the
whole document again. The diagnostic serialization counter is atomic across
independent sessions; access to one mutable session remains host-serialized.
The stamp still visits authored fields and serializes some subobjects. This
does not establish constant-time access or measured provider token savings.

## Preserved source identity

Format45 remains the published smooth/ribbon cable and endpoint-metadata
contract. Bisectors use format46. Mixed authoring saves46, old cable-only
source stays45, and unsupported downgrades reject atomically. Application
identity alone does not upgrade a drawing's source format.

Previously valid authored datums named Origin keep their transforms, kinds and
dependent references. The implicit world-zero point is used only when no such
authored datum exists. New authoring cannot claim the reserved name. Removing
a retained authored Origin rejects while consumers remain, preventing silent
rebinding to the implicit point. The UI avoids duplicate Origin rows.
Bisector graph nodes retain both authored string-anchor dependencies.

## Navigation and team work

The [navigation widget](../NAVIGATION_036A.md) and

integration. Default team context compares actual
semantic evidence; transient status/token/request metrics are now opt-in with

its own evidence. Acceptance requires actual renderer captures and coordinator
regressions, rather than a menu entry or an idle worker state.
Focused remains the default and Parallel remains available. No new agent
turn/token execution budget is introduced.
