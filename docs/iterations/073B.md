## Scope and acceptance

Separate assembly placement updates from shape evaluation. Editing a mate must
retain unchanged part geometry; any projected sketch, supported datum or other
consumer of assembly pose must still update when its actual input changes.
Sketch edits must invalidate their actual consumers and downstream dependencies,
not independent feature branches. Validate reused body identities and compare
geometry with a fresh rebuild; measure the same complete editing workloads on
072A and 073B before claiming a speed improvement.

Expose sketch-region selection, solid/surface extrusion, start offset and
explicit union with selected existing bodies, and thin-wall extrusion with
wall thickness and side selection through human controls. Preserve
editable sketch references, exact geometry, region/target validation and atomic
revision-checked publication. Unsupported or ambiguous topology must reject
explicitly. Existing files and feature recipes must remain readable.

## Extrusion contracts and limits

The shared human editor supports explicit sketch regions, new bodies, target
unions, solid/surface output, directed start offset, reverse/symmetric travel
and thin walls. Preview includes every output and Apply publishes the retained
candidate atomically. Expressions survive editing. Exact target unions operate
on part definitions, without silently retargeting assembly occurrences.
Thin walls cover simple straight polylines and a single arc/circle, without
holes; unsupported curves, collapsed offsets and invalid intersections reject.
Surface region walls include hole boundaries. Existing source-face and legacy
recipes retain their supported behavior.

New extrusion semantics use conditional authored format58; older versions
reject those recipes. Legacy recipes retain their earlier required format, and
physical container v1/v2/v3 compatibility is independent. See
[human workflow](../EXTRUSION_WORKFLOW_073B.md) and [formats](../FORMATS.md).
