# 079C — flexible cables during manual component movement

Runtime **0.9.80**. **B.04/C.04 — Verificado no escopo local**.

Studio resolves occurrence-bound cable guides against the same joint pose
used to display the carriage and chain links during a drag. The native cable
producer evaluates the affected sweeps before the viewport displays that pose.
Escape restores the original cable mesh, picking data and rigid placements.

On release, Studio refreshes previously current bakes that drive the moved
joint, using their recorded frame rates. A successful drive and bake share one
undo step. A rejected combined transaction can fall back to the checked drive
at the original revision, with the bake failure shown in the status bar.

The local Windows native tests `drag-chain-050b`, `studio-drag-chain-ui`,
`studio-baked-motions-ui` and `release-metadata` passed. The Studio drag-chain
fixture checks the displayed cable before release, Escape, a second drag,
release and subsequent flexible cable playback. These checks cover sampled
kinematics and display geometry. Physical cable dynamics and continuous
clearance remain outside their scope.
