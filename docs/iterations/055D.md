# 055D — limited task completion and stable rounded cable sweeps

Technical version: **0.9.56**. Milestones: **A.02/B.04/C.04/D.02**.
Status: **Verificado no escopo**, local verification; broader milestones remain
**Parcial**.

A completed cable edit or motion refresh could be withheld by the Single
assistant's global BOM gate because preexisting unrelated definitions lacked
internal part numbers or descriptions. An accepted specialist review did not
satisfy that gate; repeated finalization ended as an interrupted run.

Studio now establishes a host-owned baseline before a Single task or a new Team
goal. `bom_inspect.task_scope` reports changed/new counted definitions and
removals. Coverage compares authored definitions, BOM rows, referenced materials,
occurrences/placements and evaluated geometry. Native B-rep hashes bind native
geometry; evaluation keys conservatively cover other evaluated dependencies.
Models cannot reset the baseline through a tool or narrow the coverage by passing
`ids`. Steering remains within the existing task boundary.

For an explicitly limited user task, `bom_review` accepts `completion:"task"`
together with selected `ids`. The selection must cover every affected counted
definition, and the normal current-revision inspection, identity, scope,
pending-note and fastening rules still apply. The receipt is ephemeral and bound
to the current authoring digest. Later edits or another task invalidate it.
Single and Team append a host qualification that the global project/BOM remains
pending. Ordinary selected reviews and default project review retain their
previous authority. Do not downgrade a requested whole-project/detailed result.

Removal of a counted definition, unavailable baseline or more than 64 affected
definitions conservatively requires project review. This mechanism governs BOM
finalization, not geometric acceptance or a proof that all user requirements were
met. It does not add electrical ratings, suppliers, materials, fasteners or other
unrequested metadata. No document-format change, dependency or agent turn/token
budget is introduced.

Full-frame cable preparation also exposed a native rounded sweep failure at a
nearly straight waypoint (`BRepAdaptor_Curve::No geometry`). Rounded arcs now use
their known circle/plane directly. An explicitly configured pipe-shell builder
uses **1e-7 mm** geometric/boundary tolerance and **1e-7 rad** angular tolerance,
with a measured surface-error check before the existing B-rep/solid validation.
This replaces the convenience sweep builder's coarse defaults. No corner is
discarded, no obstacle/solid check is bypassed, and tolerances are not enlarged.
The electronics receipt reports the sweep tolerance and measured surface error.
