# 062B — inspection and additive build preparation

Technical version: **0.9.63**. Focus: **B**. Milestones: **A.02, A.04,
B.01, B.04, C.03, D.02, E.01**. Broader milestones remain **Parcial**.

## Delivered behavior

- **B.01:** `D` opens Smart Measure. Visible exact edges take precedence over
  faces; hover previews the target. A normal click replaces the selection and
  Ctrl-click adds/removes an entity. Line/curve length, circle/arc/cylinder/sphere
  diameter and radius, and face area come from the source B-rep. Two entities
  report exact minimum distance and applicable acute direction/plane angles;
  larger sets report total selected edge length. Dimension graphics follow the
  view and display units. The existing two-point 2D/3D tools remain available.
- **B.01/B.04:** Ctrl-click bodies in the viewport or model tree, then Spotlight
  isolates the selected occurrences. Exit Spotlight restores prior visibility.
- **B.01/A.02:** Section View accepts XY/XZ/YZ or a named datum with offset, or
  two screen endpoints defining a plane through the viewing rays. Flip and
  Offset update the view; Close/Esc restores the model. Exact half-space
  intersections produce display meshes and hatched caps, retaining internal
  holes. No source B-rep or authored placement is replaced. Measurements and
  reference authoring return to the complete source; section triangles are not
  misidentified as original semantic faces. Changed revision/epoch or display
  pose clears stale inspection. Section views temporarily use raster rendering.
- **C.03/D.02/E.01:** `manufacturing_plan` action `prepare_print_job` gathers
  declared additive outputs and BOM occurrence quantities, including hidden
  occurrences, or accepts explicit job items. It creates retained manufacturing
  plans for plates grouped by declared material, slicer profile and cut group.
  Declared build directions set orientation. Conservative exact-source bounding
  boxes determine spacing and bed fit; additional plates hold overflow. Missing
  inputs and oversized parts return blockers, without omitting or scaling parts.
  Prepared plans go through the existing revision-bound atomic preview/apply.
- The Manufacturing tab offers **Print job** and **Plates**, with a footprint
  preview and previous/next controls. The existing Bambu bridge exports all
  plate members at their planned rigid placements and records source, graph,
  plate, mesh, executable and profile fingerprints. `pending_slice` explicitly
  rejects simulation until real G-code is imported. CAD authoring is unchanged
  by planning/slicing; the retained plans are normal document data.
- **A.02/A.04/D.02:** includes the 061C follow-up fixes for recoverable assistant
  revision conflicts after manual edits and native window commands during busy
  operations. See [061C evidence](061C.md#manual-edits-and-native-window-commands-2026-10-26).

## Scope and limits

- Native B-rep remains the measurement and production geometry authority.
  The smart entity tool rejects sampled-only geometry; the existing point tool
  explicitly labels its supported mesh estimates. Inspection previews require
  the stationary formed model. Section rendering uses source-derived meshes;
  saved geometry remains complete, including geometry hidden by the section.
- Plate packing is deterministic conservative shelf packing, not optimal shape
  nesting. It does not design supports, qualify strength, infer missing printer
  profiles or physically split oversized parts. A cut group labels already
  authored parts; an actual cut is a separate CAD edit.
- Maximum retained manufacturing plans remains 32. A larger job explicitly
  rejects before publication and can be prepared as smaller explicit batches.
- Local layout/mesh export and the bridge contracts are tested. Actual Bambu
  slicing, printer-specific G-code and a physical print require real installed
  slicer profiles and are **not verified in this iteration**. No printer/cloud
  transmission is introduced. This is not manufacturing qualification.
- The earlier broad assistant test's provider tool-count abort is a separate
  known limitation; scoped assistant continuity tests are used here.
- `.ark` version is not changed solely for the application release identity.
