# 044B - motion graphs, spline patterns, textures, media and Claude Code

Runtime 0.9.45 and iteration identity come from `release.json`. Phase **B**
(CAD authoring) is the principal focus. Milestones **B.01, B.03, B.04, C.04,
D.02** and **D.04** remain **Parcial**. The scopes below are **Verificado no
escopo local**: synthetic fixtures, the regression suite and local Studio

cost claim is made.

Geometric authority, `expected_revision`, atomic publication and explicit

## Skeleton Motion and Baked Motions (B.04, C.04, D.04)

Agents author a vector motion graph over existing revolute and prismatic
joints, not a keyframe list:

- **Segments:** hold, linear, ease, cubic Bezier in (time, value), sine, spring
  and function.
- **Composition nodes:** sequence, parallel, delay, repeat, ping-pong, reverse,
  time-scale and offset.
- **Couplings:** expressions between channels, such as an elbow following a
  shoulder.

`motion.graph.set`, `motion.bake`, `motion.rename` and `motion.remove` run
through revision-checked `doc_apply`. The read-only `motion_info` tool reports
continuity, ranges, bindings, stale status and individual frames.

Baking drives every frame through the existing joint solver, including
constrained continuation for closed loops, and checks each channel against its
target. Only moving instances are stored, as compact float32 poses. A source
digest of nodes, mates, parameters and solved placements marks a bake **stale**
after any later change. A stale bake stays playable.

Studio adds a **Baked Motions** panel docked to the right of the viewport. It
lists each motion with a BAKED, STALE, NOT BAKED or INVALID badge, draws the
vector graph with its handles and continuity markers, and offers a timeline
scrubber, Play/Pause/Stop, Loop, speed, Rename, Bake and Delete. Playback only
replaces display transforms; Stop restores the solved pose.
[Contract](../SKELETON_MOTION_044B.md).

## Patterns along chains, splines and surfaces (B.03, B.04)

`curve_pattern` now follows several kinds of path:

- an auto-chained list of `references[]` with one arc-length parametrization;
- a whole wire feature: curve, spatial spline, intersection or bridge curve,
  or a spline cable centerline.

It supports:

- **Spacing:** `count` from 2 to 2048, or `pitch_mm` with fit/truncate, plus
  margins, phase and `skip`.
- **Closed loops:** no duplicate copy at the seam.
- **Orientation:** `x_hint`, `frenet` or `surface`, with optional projection
  onto support faces and a reported deviation.

Copies are located shapes that share the seed geometry. With
`reference_scheme:"compact"`, the number of copies is bounded by the existing
16384-entry selection inventory instead of the earlier 512-name limit, for
example 2048 copies of a cylinder seed. Requests with only the earlier fields
evaluate unchanged; their B-rep and reference digests match the previous
build. 2000 copies took about 1.2 s in the worker and 2.9 s through `doc_apply`.
[Contract](../CURVE_PATTERNS_044B.md).

## Textures and animated media (D.04, B.01)

Appearance accepts procedural patterns, needing no image file: twill, weave,
carbon, leather, brushed, knurl and perforated. Studio shades them triplanar,
with roughness and bump relief. Embedded image textures now tile instead of
clamping to their edge color, the likely reason textures did not appear.

Stamps accept animated GIF and MP4 (H.264) assets with `loop`, `speed`,
`autoplay` and `start_s`:

- **GIF:** embedded in the document and decoded with the bundled portable
  decoder.
- **MP4:** referenced by a path relative to the document plus its SHA-256,
  with optional embedded bytes. It is decoded by Media Foundation loaded at
  run time, on Windows only, without audio.

The software `snapshot` now draws triplanar textures, patterns and surface
stamps at `media_time_s`. Missing, mismatched or undecodable media report an
explicit status and draw nothing. [Contract](../MEDIA_TEXTURES_044B.md).

## Claude Code inside ARK (D.02)

The Assistant and Team cards offer **Claude Code / CLI account**. ARK starts
the Claude Code CLI that the user installed, unmodified, and serves the role's
tools to it as an in-process SDK MCP server. ARK executes every call itself.

Built-in file, shell, web and subagent tools are disabled. The CLI's session
init must list only the role tools, or the process stops before any CAD call.
The CLI authenticates exactly as the user configured it; ARK reads, stores and
supplies no Claude credentials. Usage comes from the CLI's result receipts.
`ark-benchmark` accepts protocol `claude_code`.
[Contract](../CLAUDE_CODE_CONNECT_044B.md).

## Not established

- **Motion:** baked motion is ideal kinematics. Dynamics, contact and
  continuous collision are not checked, and `clearance_checked` is false.
- **Media and appearance:**
  - only H.264 video on Windows, without audio;
  - other GPUs and long or high-resolution clips are unverified;
  - the software snapshot is flat-lit and draws no plane stamps.
- **Curve patterns:** there is no Studio authoring panel for the new fields,
  and Frenet frames can flip at inflections.
- **Claude Code:**
  - only one CLI version on one machine was checked;
  - image input on that route is not qualified;
  - no design quality or cost comparison was made.
