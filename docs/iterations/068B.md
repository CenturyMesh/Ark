### Composed fixture and independent checks

The final native binaries ran this synthetic sequence:

1. Construct two compatible cubic Gordon-network surfaces and inspect their control nets.
2. Move interior poles by 0.4 mm while locking boundary poles.
3. Match G2 to the second surface: initial 3 mm gap / 1.718358 degrees / 0.00848528 mm⁻¹ tensor error became 0 gap / 0 angle / 8.538×10⁻¹⁹mm⁻¹ over 65 native checkpoints.
4. Inspect 81 curvature samples, sew two faces into one connected open shell and create checked 0.25 mm thickness.
5. Export STEP, read it back, save/reopen the editable document and re-inspect the seam. Original source/target B-rep hashes remained unchanged.

The native volume was 301.5157897318 mm³ versus 301.5157896956 mm³ from independent integration of the explicit analytic offset strip (difference 3.62×10⁻⁸mm³). STEP readback differed by 8.6×10⁻¹¹mm³. This is a local OCCT/ARK round trip, not independent-recipient CAD or manufacturing qualification. The final-byte receipt, reproducible harness and synthetic outputs are retained under `verification-068b/surface-interop-release` in the local build tree.

## Failures retained and resolved

- Compile integration found missing helper/header declarations, an unsupported OpenGL token, a deleted neighboring legacy function and the long command-line parser's compiler nesting limit. The original neighboring functions were restored and the new flags parse independently.
- Native SDK inspection corrected an arclength solver overload: its fourth argument was an initial guess, not a tolerance. Native/host tests were rerun after the correction.
- Initial UI tests exposed names treated as numeric expressions and a fixture missing expected_revision. Unique-name/ID resolution and explicit revision binding fixed these paths.
- Extension without holes exposed a native builder state assumption: a face-copy builder was not marked done until an inner wire was added. The already validated extended face now handles the zero-hole case; both holed and unholed analytic-area regressions pass.
- Review screenshots exposed a missing bitmap and overlapping multiline footer. The shared editor now displays/scales the actual candidate image and bounds the report above Apply/Cancel.
- Visual/interaction review corrected per-triangle zebra artifacts, clipped essential units, stale occurrence overlays, paired-picker ambiguity, unintended loft dependencies and result selection after Apply.

## Limits

Matching requires the documented compatible polynomial BSpline boundary basis; rational, periodic, trimmed or incompatible cases reject. Networks support 2–9 curves per family in the documented single-span polynomial domain, not arbitrary rational/multispan reconstruction. Group editing keeps the existing bounded control-net domain; boundary locks preserve positions, not automatically G1/G2 derivatives.

Continuity, curvature and deformation samples do not certify between-sample extrema or global continuity/injectivity. Native interference checking is explicitly identified and is not a universal mathematical proof. Extension requires the supported rectangular outer UV boundary; arbitrary trim extension remains unsupported. Sewing reports gaps but does not enlarge tolerances to heal them. Offset risk points alone are not proof of the failure location.

Only the affected 14 Studio suites were run here; historical unrelated failures are not declared repaired. There was no real-model quality/cost comparison, physical manufacturing qualification, clean-machine audit, signing or online-update deployment. User drawings and the live installed application remain outside test fixtures.
