Runtime `0.9.17`, baseline `015B` / `ae5ec5c`. Milestones
A.01/A.03/A.05/B.01/B.05/D.02/F.03/G.04. Detailed receipts are recorded in

The project owner explicitly adopted Apache-2.0 and authorized publication of
`CenturyMesh/Ark`, including its Git history, after review. LICENSE and NOTICE
cover ARK's original code/documentation; dependencies retain their own terms.
User drawings and imported third-party content retain their own rights.

## Documentation and contribution workflow

The English README, handbook and documentation index now provide build/launch,
authoring, agent connection, BOM and verification guidance. CONTRIBUTING and
issue/PR templates describe scoped branches, useful reproductions, appropriate
tests and release identity. The roadmap preserves all 35 stable IDs and keeps
qualification boundaries visible. The old README and Portuguese roadmap are
archived as dated technical evidence; public licensing guidance records the
adopted source license and distribution boundaries.

## Connectors and native UI

Connect, Providers, 2D/3D measurement, units, BOM, revolve, offset, sew and tube-end
fit have dedicated shared vector icons in ribbons and native menus. The Connect
export uses readable TOML/JSON, correct Windows line breaks, read-only text and
Ctrl+A selection. Semantic/exact copy checks cover all four client profiles.
Switching from an API connector to ChatGPT plan clears incompatible model/effort.
About reports the adopted license. Captures were inspected at 1180 and 1600 pixels.

External MCP and internal assistant authentication are documented separately.
ARK owns its ChatGPT OAuth registration and DPAPI store; it does not borrow Codex
credentials. Local bridge ACLs, PKCE/state/nonce and identity checks were reviewed
in source. Offline tests and configuration exports are not a fresh live provider
sign-in, an external-client certification or an independent security audit.

## Distribution and security

Windows archives retain ARK's license/attribution both at the root and under
`licenses/`, because the versioned local installer retains that directory.
Packages exclude user drawings and credentials. Git ignore rules protect new
local drawings/account files without removing previously tracked examples.

Gitleaks 8.30.1 scanned the 43 pre-release commits. Nine detections were reviewed:
two C++ field comparisons and seven upstream SQLite macros/comparisons. Exact
historical fingerprints are ignored; no broad source-file exclusion was added.
No real credentials were identified in that scan. Author metadata uses the
existing GitHub noreply identity. This is bounded evidence, not a guarantee that
automated scanning detects every possible private datum.

The trusted Windows update channel changes from the unused `Ark-Releases`
placeholder to `CenturyMesh/Ark`, retaining exact URL and integrity checks.
The first public binary is a prerelease for manual evaluation; GitHub's stable
`latest` endpoint excludes it. Existing builds pointing to the placeholder need
a manual transition. No online automatic upgrade trial or signing is claimed.

GitHub Sponsors is not active for CenturyMesh at preparation time. The setup
guide explains owner identity/payout/tax/2FA steps; no fictitious donation link,
payment tier or support entitlement is published.

## Platform scope

Windows provides Studio, CLI, MCP and the native worker. Linux build scripts,
target-specific metadata, CI and a relocatable headless package provide CLI/MCP
and native OCCT. Linux has no Studio GUI, named-pipe live Studio bridge, built-in
Windows authentication transport or OTA manager. See the verification receipt
for actual build/test/package outcomes and dependency requirements.

The first Linux SDK attempt exposed an implicit X11 dependency; `USE_XLIB=OFF`
selects the supported headless configuration. The first native test pass exposed
missing transitive shared-library lookup in the installed SDK; relative sibling
library lookup fixes that configuration. These failed attempts remain in private
logs and are not presented as geometry or design-performance improvements.

The 009B pilot remains closed at nine attempts, one accepted. No new live model
pilot, performance comparison, user-design benchmark or industrial qualification
was run for this iteration.
