## Failure and recovery

activity was not a stuck kernel worker. Exact baseline/request bundles remain
private and are replayed offline. Investigation did not start another provider
run. Earlier paid trials, including their failed attempts and incomplete usage
records, do not establish a cost improvement for this iteration.

Missing query projections such as `plane` or `references` previously discarded
other successful rows. Recovery now preserves each observed result and its
available fields, returns executable recovery arguments, and records partial
failure accurately. Structural validation precedes execution and each query
runs once. The coordinator associates failures with the exact role, project,
query and revision; unrelated success cannot clear them.

Retained recovery packets survive subsequent context projection. A successful
matching query retires the packet; historical receipts never authorize writes.
A changed selector for the same object may explicitly supersede a rejected read
through `team_report_task`, `state:in_progress`, exact query identities, a reason,
and that role's later successful current-revision receipt. The entire list is
validated atomically. Writes, previews, completion and engineering approval
cannot be waived. `expected_revision` and atomic publication remain unchanged.

## Native source corrections

The pinned OCCT 8.0.1 patchset changes 18 source/header files:

- The affected C2 independent-dimension, two-pass-point variational loft uses
  the original least-squares factors through
  augmented QR, preserving its objective and constraints instead of numerically
  unstable normal equations. High-precision and analytic translated/scaled
  controls pass. Recomputed geometry can differ from the old inaccurate result.
- Multi-curve assembly reduces a shared knot only when every component supports
  the same parameter ratio. Otherwise it preserves the exact Bezier components.
  Invalid joins, non-finite knots and stale successful-result state are rejected.
- Surface intersections retain mandatory continuity boundaries, one-sided
  derivatives, consistent XYZ/UV state and the complete parameter interval.
  Simultaneous identical boundary events are deduplicated; nearby distinct events
  remain. Both GeomInt and BRepApprox consumers are covered, including rigid poses.
- Offset edge extension preserves the original pcurve interval and its mapping.
  Only the extension is projected onto the original supports, with an explicit
  creator supplying the 3D curve. Active pcurves and support surfaces are retained.
  Unsupported mappings reject explicitly. No acceptance tolerance is enlarged.
- The offset-surface isoline shortcut must satisfy its requested physical error.
  Otherwise the existing approximation of the same authoritative input is used
  with unchanged constraints and limits; analytic fast paths remain covered.
- Native integration splits at actual curve/continuity spans. A synthetic prism
  demonstrates 370 mm3 where the original missed spans returned 286.6667 mm3.
- Failed face/face intersections propagate through the Boolean and offset
  callers. An injected failure rejects the shell at its own feature without
  publishing a partial result or advancing the revision.

The original cumulative refinement counter is retained. A proposed counter
change was excluded after paired controls showed changed work without an
acceptance benefit. No default fitting tolerance or geometry fallback was added.
