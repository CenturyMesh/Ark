# 082D — Viewport snapshots in chat

Runtime **0.9.83**, milestones **B.01** and **D.02**.

**Snapshot** in the Studio composer captures the current 3D view. The viewport
context menu offers **Snapshot for agent** beside **Ask Agent about this object**.
The user can orbit, add more views, review each thumbnail, and send a question
or queue a direction for a running agent. Each image carries its capture
revision. A message can also include imported inspiration or Image to CAD
references with their own shared authoring intent.

Twelve focused Windows checks passed. The Studio tests rendered a synthetic
model, captured it through the
composer and checked the actual PNG payload, revision and accompanying text
using an offline provider transport. The steering test queued a new direction
while work was in flight and checked rejection of the superseded write. A
failed GPU capture preserved the pending references. Team tests checked the
snapshot bytes and revision alongside imported references. Visual inspection
covered the context menu and two Studio window sizes. Provider interpretation
of a particular design was outside this verification.
