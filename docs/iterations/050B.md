# 050B - native drag chains and sketch capacity

Runtime 0.9.51 and iteration identity come from `release.json`. The principal
phase is **B**. Milestones **B.04/C.04/B.02/A.02** remain **Parcial**.

## Delivered behavior

- `drag_chain.set` creates a reusable cable carrier with one native link solid
  and driven assembly occurrences. The fixed run stays still, the moving end
  follows a prismatic carriage, and the bend rolls through the links. Edits,
  replacement and removal are revision checked and atomic.
- `drag_chain_info` inspects the recipe and hypothetical carriage positions.
  Assembly/motion onboarding and the lead engineer's command scope include it.
  There are 108 discoverable tools.
- Baked carriage motion includes the driven links, using 049A derived-frame
  receipts. Recipe edits invalidate previous bakes. Sampled exact motion
  clearance involving followers cannot claim continuous certification.
- Studio displays the chain state in the selected link's Properties tab,
  including during baked playback.
- The document-wide sketch limit is 256, shared by every part and assembly.
  Each command batch still allows at most 128 operations. Saving and loading
  use the same sketch limit; overflow rejects without partial authoring.

See [the chain contract](../DRAG_CHAIN_050B.md) for geometry, supported inputs,
kinematics and rejection codes. This work does not establish dynamics, sag,
cable fill, fatigue or manufacturing qualification. The document format is not
advanced merely for the application identity.
