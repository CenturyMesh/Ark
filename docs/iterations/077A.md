# 077A — document opening, rebuild reuse and memory

Runtime: **0.9.78**. **A.02 / A.03 / A.04 / B.02 — Verificado no escopo local**;
**F.05 — Em curso** until the distribution receipts pass.

This iteration addresses a document-open rejection during surface-area
integration and unnecessary native rebuilds when the scheduler changes its
thread allowance. Geometry, topology references and revision checks remain
authoritative; no document-format change is introduced.

Implemented changes:

- Select area integration per face and accumulate absolute error estimates
  before checking the existing 1e-10 relative precision of the total area.
  OCCT's aggregate return is the maximum *face-relative* estimate.
- Bind persistent native cache keys to the resolved geometry request, excluding
  the top-level scheduling allowance, as portable request identity already does.
  Canonicalize and serialize the request once for both identities. Solid offsets
  now participate in exact local reuse and validated portable restoration;
  their repeated reconstruction previously invalidated downstream requests.
- Evaluate independent explicit PCB/cable programs on the bounded worker pool;
  occurrence-bound inputs retain owner-thread resolution.
- Retain decoded native meshes in lossless typed channels. Independent JSON
  reads do not leave an expanded numeric tree in the cache, and expansion does
  not hold its shared mutex. Disk hashes are still checked on every lookup.
- Move validated saved payloads into staging rather than duplicating their
  strings. Successful expensive volume integrations have a bounded worker-local
  memo keyed by the complete current serialized B-rep and requested moments.
  Pointer identity, meshes and earlier reports do not establish geometry.
- Add a read-only `ark-performance-regression --profile-open FILE` diagnostic
  with per-feature results, stage times, source/topology digests and cache counts.

## Limits

Fast repeated opening depends on authenticated local geometry results. An empty
cache, a changed producer or older saved request identities can still require
substantial replay and exact snapshot validation. Saving an equivalent copy
refreshes its portable derived results but does not remove all cold-open cost.
The requested 5–10 second target is not qualified for every cold-cache case.
No geometry simplification, omitted solid, history pruning or document-format
change is used to obtain the warm-open improvement. Manufacturing qualification,
trusted signing and remote publication remain separate gates.
