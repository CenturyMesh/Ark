## Editable cables and human path guidance

New explicit `route_mode:spline` creates an interpolating native 3D curve with a
round or rectangular ribbon sweep. The retained program uses start, ordered
waypoints and end, optional world-space endpoint tangent directions, and a
declared ribbon thickness direction. Native receipts expose the actual curve,
degree/knots, length, sections, curvature bounds, B-rep self-interference and
declared-obstacle clearance. Original rounded-polyline programs stay unchanged.

Electronics > Guide path exposes draggable anchors on the selected cable.
Pointer changes update retained GL control geometry immediately; a separate
immutable worker coalesces exact candidates. Only the latest matching
gesture/revision/epoch can publish after release, with one Undo per gesture.
Driven expressions stay protected, and occurrence-bound anchors edit their
retained offset. Escape, capture loss and source drift cancel. Orbit between
gestures to change the drag plane. This is not elastic cable simulation or GPU
native geometry evaluation. See [the cable contract](../ELECTRONICS_035B.md).

Only these new cable semantics select source45. Old recipes retain the earlier
format they need; save/load/history rejects unsupported downgrades atomically.
Application identity and document format remain independent.

## Plastics and component sourcing

[Plastics](../PLASTICS_035B.md) groups exact hollow walls, draft, support-bound
ribs/bosses/mounts/lid fits, vents/edge treatment and explicit plane separation.
The existing native producers remain authoritative. The official Fusion
documentation informed workflow organization; no automatic mold parting,
shut-off, core/cavity, mold flow or resin shrinkage qualification is implied.

[Approved Vendors](../APPROVED_VENDORS_035B.md) separates local network approval,
public catalog discovery, browser account access and authenticated API status.
An observed product link is distinct from a retrieved STEP: actual status,
bytes, redirects, SHA256, native body selection and source evidence are retained.
HTML/login/ZIP masquerading as STEP rejects. Policy updates use their own
observed revision and crash-releasing writer lock. No passwords/cookies/tokens
are stored in the registry, project graph or curated notes.

The public KiCad/GitLab discovery/download path is implemented. Authenticated
commercial adapters remain explicitly unconfigured until their actual API
credentials, entitlements and adapter contracts exist. An approved domain or a
successful import does not prove requested manufacturer/reference, license,
electrical behavior, stock, price or manufacturing qualification.

## Shared graph and Obsidian knowledge

`context_graph` now navigates authored cable endpoint/occurrence links, PCB
component envelopes, PCB-scoped net labels, supplier/source URLs and stored STEP
artifact metadata. Relations are attributed authoring/navigation evidence.
Approval-at-retrieval is historical; it does not override the current policy or
certify electrical connectivity. Credential-bearing links stay excluded.

The local code graph and separate Obsidian export include four curated linked
guides in `docs/knowledge`: Electronics, Plastics, Vendors and Workflow. The
vault key includes code-graph and knowledge hashes, so note-only changes get a
new export without reparsing unchanged code. Every generated canvas card and
wiki link is checked; personal vaults and prior exports remain untouched.
