# 053B — reusable parametric components and graph navigation

Technical version: **0.9.54**. Milestones: **A.02/A.03/B.01/B.04/E.01**.
Status: **Verificado no escopo** locally. The broader milestones remain **Parcial**.

`.arkprt` and `.arktop` store authored reusable definitions with stable identity,
explicit revision chains and public parameter/datum interfaces. A project embeds
the selected revision and remaps its source into an independent namespace.
Updates use checked candidates, retain root placement and reject local divergence
or structural identity changes. Conditional semantic format 51 persists bindings;
the owned binary container and `.arkops` replay meaning remain unchanged.

Neural Parametric View is a native modeless window over the local authored graph.
It connects geometry selection, parameter dependants, groups and embedded reuse.
Search, focus, folding, layout, pan and zoom do not issue model calls or edit the
document. The index's incomplete dependency coverage remains explicit.

See the [contract and boundaries](../PARAMETRIC_COMPONENTS_053B.md).
