## Geometry Nodes

The native editor adds typed source/operation nodes, connection gestures,
parameter editing, deletion, and ordinary document undo/redo. Meshes, exact
surfaces and solids retain distinct contracts. Explicit sampling produces a
mesh; it never infers a solid from triangles. Links are the existing authored
feature inputs, not a separate model or a new `.ark` format.

Human edits prepare an isolated checked candidate. The review presents actual
current/candidate snapshots, changed-node records and measured evaluation/reuse
counts. Existing-target comparisons use a shared camera and image scale.
Apply publishes the reviewed candidate; Cancel/stale paths release its retained
proposal and images without changing current source. See
[Geometry Nodes](../GEOMETRY_NODES_078B.md).

## Resource management

- Native calls share a bounded resident pool, FIFO CPU admission and cancellation
  controls within one host process. Leases isolate each request/result pair;
  idle workers are recycled and only their own I/O handles are inherited.
- RAM admission accounts for the actual captured dependency closure and native
  request working data. Immutable shared geometry is not charged as a new full
  document for every job. Shutdown lifetime fixes preserve producer pins and
  authenticated cache reads while the host's thread pool drains.
- Display uploads reclaim idle buffers before allocating incoming data, keep
  active owners, hash existing source buffers without concatenating them and
  use bounded packed-vertex staging. Failed uploads remain explicitly incomplete
  and cannot produce successful viewport evidence; rendering can be retried.

See [shared scheduling](../RESOURCE_SCHEDULING_078B.md) and
[display memory](../DISPLAY_MEMORY_078B.md). These are demand-driven policies,
not an operating-system-wide CPU or VRAM reservation guarantee.

## Agent context and Obsidian

Project graph reads have revision/source-bound continuation, directional node
traversal, bounded incident-edge chunks and explicit boundaries. Geometry-node
inspection avoids transmitting complete native/mesh payloads. The first audited
graph read establishes its scope before returning a cursor. Specialist loading
exposes the actual geometry tool and preserves continuation evidence in context.

Code-only Obsidian exports add a navigator, curated knowledge links and source/
coverage receipts. Stale index/vault combinations reject; edited exports and
prior versioned vaults remain protected. See [context scope](../AGENT_CONTEXT_078B.md).

The catalogue now has 125 CAD tools. Team catalogues preserve the existing
128-function transport bound, including an enabled result-handle helper, through
explicit coordination aliases only when needed. Proposal reads and reservation
release retain their original guards; no CAD capability is silently dropped.
Geometry-node candidates follow the Team's existing ownership and command-scope
checks. Read-only reviewers receive inspection/catalogue actions, not preparation
or publication rights.

A UI control, proposed candidate or graph edge is not evidence of a committed valid CAD operation.
Native B-reps and producer contracts remain authoritative. No implicit
mesh-to-solid conversion, silent rebase or user-history pruning is intended.

Focused remains the default agent mode. No provider turn/token budgets or
claims of design-quality or token-cost improvement are introduced.

Connections remain constrained by authored feature order; the editor does not
silently reorder history or detach program/component ownership. Canvas layout
is session UI state. Graphs are navigation evidence, and AST coverage may be
partial. Geometry inspection still hashes the complete semantic source; bounded
responses are not a constant-processing-cost claim. Cold-cache opening and
manufacturing qualification remain separate acceptance criteria.

Distribution receipts will be recorded after packaging. User drawings and private
acceptance evidence remain outside public fixtures, source, installers and update
packages. No live-provider quality/cost benefit is claimed.
