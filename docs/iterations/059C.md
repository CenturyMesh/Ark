# 059C — rubber authoring, surface patterns and derived dynamics

Technical version **0.9.60**, sourced from `release.json`. Milestones
**A.02/A.04/B.01/B.04/C.04/D.02**. Status: **Em curso**; verification pending.

## Implementation scope

- Exact editable `native_solid` operation `rubber_body`: belt/track racetrack,
  elliptical tire and solid/hollow ball. Numeric expressions remain authored
  parameters. Optional bounded exact relief fuses reusable motifs and rejects
  invalid/disconnected results atomically.
- Indexed procedural placement on cylinder, torus, sphere and racetrack,
  including circular, helical, chevron, braided and spherical distributions.
  Dense visual pebble/traction/chevron detail is distinct from exact geometry.
- Derived XPBD surface network, CPU reference and hardware D3D11 compute,
  ground/pulley contact, friction, explicit anchors and material inputs.
  Native CAD supplies total volume/mass. Link stiffness is a reduced model;
  it is not a calibrated continuum rubber or tire handling law.
- Agent `rubber_plan`, lazy rubber onboarding and parameterized command recipe.
- Native body click followed by Tab/Shift+Tab cycles exact canonical faces of
  the same occurrence while preserving editing/text-control precedence.
- GPU snapshot inspection while Studio is minimized or its viewport collapsed
  is being addressed without requiring the user to restore the window.

## Acceptance and limits

Verify analytic native volumes, invalid-input rejection and atomic rollback,
recipe persistence, deterministic frames and bounded pattern paging, material
and mass authority, CPU/GPU solver agreement, anchors/contact/friction,
revision/cancellation guards, and inspect actual native UI captures.

No pressure/volume conservation, self-contact, fatigue, thermal coupling,
calibrated tire contact or manufacturing qualification is claimed. No runtime
speed advantage is claimed before equivalent measured comparisons. No change
to the `.ark` document version is required by the release identity.

## Technical sources

- [XPBD paper](https://matthias-research.github.io/pages/publications/XPBD.pdf):
  compliant position constraints and their relationship to energy.
- [Project Chrono tire models](https://api.projectchrono.org/development/wheeled_tire.html):
  distinguishes rigid, handling and deformable tire model scopes. ARK does not
  claim a Chrono integration or implement its calibrated tire models here.
- [GPU Gems procedural terrain](https://developer.nvidia.com/gpugems/gpugems3/part-i-geometry/chapter-1-generating-complex-procedural-terrains-using-gpu):
  procedural surface detail and triplanar texture blending as rendering techniques.

Local implementation and verification evidence will be recorded after the
integrated build. The pattern combinations are ARK options, not a claim of
scientific novelty or state-of-the-art superiority.
