# 019B — visual and parametric modeling

Runtime `0.9.20`, principal phase B. This iteration contributes to A.01/A.05,
B.01/B.02/B.03, C.04, D.02/D.04 and E.01. The authoring, engineering, agent and
contract milestones remain **Parcial**; human acceptance and merge are pending.

Portable PNG/JPEG decoding retains the pinned upstream codec, full license and
provenance in native/headless packages. This is dependency notice evidence,
not an independent licensing audit.

Actual image attachments reach Assistant and team transports with two intents
and optional rough Width/Height/Depth. Editable modeling now includes native
Skeleton code, bounded source-face push/pull, indexed mesh patch/vertex/edge
operations, visible driving sketch dimensions and body/curved-face selection
feedback. Solid operations have distinct Fuse/Carve/Keep overlap labels.

The direct model-click follow-up adds persistent Body/Face/Edge/Curve controls,
depth-aware cyan hover feedback and plain-click replacement with Ctrl/Shift
selection accumulation. Selecting a mode exits authoring and latched navigation
that previously consumed clicks. Native surfaces, lofts, Boolean results,
patterns and STEP imports receive complete bounded selection inventories;
producer names take precedence over exact-identity fallback handles. Mesh
panels and edges use distinct source-index selections. Display caches reuse
body adjacency and stationary silhouettes without changing document geometry.

Native helix sources can feed sweeps/lofts. Surface joining exposes connected
sewing and free-boundary diagnostics. Loft section alignment and strict guide
controls affect the native builder, with observed deviation evidence. Collision
inspection distinguishes exact solid distance/overlap from labelled triangle
contacts and bounded containment checks. Neither supplies physical response.

Source semantics use document format 35 only when needed. Ownership, source
roundtrip, old-version rejection, current revisions and atomic candidates remain
part of the contract. Private drawings and reference images are excluded from
public fixtures, packages and verification images.
