# 022B — responsive direct edits, component patterns, sheet programs and drawings

Runtime `0.9.23`, principal phase B. `release.json` owns this identity. The
iteration addresses A.01/A.03/A.04, B.01/B.02/B.03/B.04/B.05, C.01, D.02/D.04
and E.01. Those milestone scopes remain **Parcial**, except the established
release-identity contract. Manual user acceptance and merge are pending.

The next drag after a sketch extrusion edits its existing source-owned solid.
Explicit planar-face extrusion remains available. Direct preview work is
coalesced on a persistent background worker; the viewport updates gesture values
without synchronously running each native operation. Apply adopts an opaque
validated receipt only after checking source fingerprint, revision, epoch and
latest gesture/generation. Preview geometry is uploaded once per completed
generation. Capture detaches the mutable activity ledger; commit preserves live
activity and usage. Host shutdown joins the preview worker before global executor
teardown.

Exact native vertex pulls use current topological vertices and the observed
B-rep digest. They retain an editable input/displacement recipe and explicitly
facet affected nonplanar quads. Geometry, selfinterference, stale sources and
persisted recipes are checked; curved/holed/complex face domains reject.

Component patterns add source-linked inheritance, named sketch/spatial points,
exact whole-wire arc-length stations, tangent frames and alternating chain
definitions. Skips preserve stable occurrence identities. Authored sheet
programs add bounded miter and contour flanges, corner operations, edge rips,
paired tabs/slots and keyed bend allowances. These are exact local domains,
with explicit limits; assembly-fit and physical manufacturing qualification
are separate from valid geometry.

Manufacturing drawings occupy the existing CAD viewport and bind to parts,
occurrences or root/group assemblies. Original editable vector templates,
dimensions, caller-declared tolerances, exact sections and clipped hatches
share source identity with the 3D model. Source edits make measurements stale;
an observed-revision refresh is explicit. Opening the viewport/catalog is
read-only. **Agents write or export 2D drawings only when the user explicitly
requests drawing work.** Modeling, BOM completion and manufacturing review do
not trigger sheets automatically.

The independent Astra audit found and drove fixes for synchronous previews,
pending-release races, mutable audit sharing, shutdown ordering, scheduler
allocation and timing accounting. Resident native processes now accept request
allowances without restarting merely because the allowance changes. Exact
CPU geometry, bounded isolated workers and GPU display remain distinct; this
iteration does not implement a general GPU CAD kernel or claim global scaling.

Document version **37 is conditional** on specialized patterns/skips, advanced
sheet recipes, native vertex pulls or extended drawing sources/templates.
Legacy documents keep their earlier required format. Existing identity,
revision rejection, atomic publication, journal validation and Undo are retained.
