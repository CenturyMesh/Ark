# 054B — design families, editable electrical sheets and flexible cable playback

Technical version: **0.9.55**. Milestones: **A.02/B.04/B.05/C.04/D.02**.
Status: **Verificado no escopo**, local verification; broader milestones remain
**Parcial**.

The [054B contract](../DISCIPLINES_SCHEMATICS_054B.md) defines editable native
schematics with explicit pins/nets, sheet-specific BOM and DXF/SVG/CSV exports;
classification metadata and local Eye visibility filters; and native cable
preparation at baked poses. Conditional semantic format 52 preserves the new
metadata without changing the owned binary container. Three discovery tools
extend the catalog to 113.

### Long cable preparation measurement

With `ARK_CABLE_LONG_TEST=1`, `ark-drag-chain-050b-tests` additionally prepares a
14-second synthetic motion at 30 fps: **421 frames**, **419 distinct native
requests**, **424.201 seconds** of initial preparation and **406235888 bytes**
(387.42 MiB) of retained display cache. Decoding the 421 cached frames took
**2708.89 ms** (6.43 ms/frame). This excludes GPU upload, BVH updates and rendering;
it is not evidence of achieved 30 fps playback. Local compilation/UI checks also
ran during parts of this single measurement, so it is not an isolated performance
benchmark. Preparation remains expensive and the cache is process-local. The
512 MiB cache cap was not reached. Fewer baked frames reduce preparation work.

The test validates native sweeps at the sampled poses; it does not establish
constant cable length, mechanical strain, fatigue or continuous clearance.

### Issues found and resolved

Integration tests caught omitted metadata publication fields and loading a sheet
after history validation; both paths now retain complete authoring before the
history check. Discovery tests caught an omitted onboarding allowlist entry;
schematic guide loading and deferred tool activation now pass. Classification
lookup remains a core tool. An initial restriction on all stale playback was
narrowed to flexible cables, preserving the existing rigid-only inspection
contract. A native worker held open by the long test prevented an intermediate
relink; the completed final build ran after the test exited.

Synthetic fixtures were used throughout; no user drawing was edited or included
in source artifacts. Hosted CI, external DXF recipient interoperability and
electrical/manufacturing qualification are not claimed.
