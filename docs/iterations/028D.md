# 028D — Grok Build inside Assistant/Team and open chat on first launch

Milestones **A.03/F.03 — Verificado no escopo** for the observed native protocol
and chat controls; **D.02/E.01/F.05 — Parcial**. Broader roadmap acceptance
remains separate. Runtime identity is **028D / 0.9.29**
from `release.json`; document/container formats are unchanged.

Grok Build is a CLI-account connector inside ARK's Single Assistant and each
Team card. It uses the official ACP protocol and a role-owned reverse MCP
callback, with the actual model-visible tool catalog. It does not use a generic
live document bridge to bypass Team permissions or transfer a CLI subscription
into the existing xAI API connector.

The CLI keeps its authentication store. ARK isolates the process configuration,
denies external filesystem/terminal tools, preserves source revisions and host
permission checks, retains actual tool receipts after interruption and rejects
unsupported image inputs. No new runtime turn/token budget or cloud fallback
is introduced. The exact SDK-MCP capability and CLI model are negotiated.

The chat panel starts open when no visibility preference exists. Closing or
opening it through the actual control saves that choice for later starts;
the design and document format are unchanged.

  model `grok-4.7`; image input was false. This probe sent no prompt or browser
  request. Early session probes rejected before any model prompt.

  `GrokBuild:search_tool` / `GrokBuild:use_tool` enabled.
- Native protocol tests cover real host callbacks, filtered tool discovery,
  read-only/scoped roles, complete messages, interruption, cancellation,
  retained receipts, steering and inspection before resumed writes.
- UI tests exercise CLI account/model selection, foreign-setting reset,
  per-card isolation, persistence and the first-launch chat visibility control.

  **4/4**. An earlier full native/Studio checkpoint passed **132/132 in 291.51s**;
  the subsequent live CLI probe exposed full registry IDs and legal nested
  request-ID reuse, which were corrected before final distribution.
- The first full run had one visual measurement failure: the open chat reduced
  viewport height and the fixed crop excluded actual contact-shadow pixels.
  The adaptive crop retains the requirement for four distinct shadow modes.
- Final full-suite, authenticated scratch authoring, hosted Windows/Linux,
  relocated package and checksum results are recorded in the
