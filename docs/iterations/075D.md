but older unqualified guidance still contradicted the opt-in domains. Current

contour fillets, native thin offsets and rational/common-basis surface options.

protocol additions in `docs/AGENTS.md` are explicitly labeled as history.

assembly and automation guides, including the preloaded authoring pack. Tool
schema checks cover compact/detailed discovery and the new surface, region and
evaluation parameters. Source format remains 59; no geometry changes are made.

static developer guide, and duplicate static guide messages are deduplicated.

remain intact. Caller-owned input history is not modified. Empty configurations
and user quotes of the marker are not treated as permission to erase content.

The Single-agent interactive instruction is now a field of the JSON guide pack.
Previously a raw suffix made that pack unparsable for preloaded-tool discovery,
although its text was visible to the model. Team role packs remain topic-scoped.

from an old chat, preserved evidence, idempotence and no CAD mutation. Connector
tests use their existing offline/native seams; no paid model request or live
credential change is required. Existing running runtimes need the update and a
restart; the refreshed guide is supplied on a subsequent assistant interaction.
