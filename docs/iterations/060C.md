# 060C — additive and CNC manufacturing graph

Technical runtime **0.9.61**, from `release.json`. Milestones
**A.02/A.04/C.03/C.04/D.02/E.01** are **Verificado no escopo local** for this implementation and
remain **Parcial** overall.

The scope is a native C++ manufacturing DAG integrated with document authoring,
revision-bound preview/apply, shared agent context, Studio and Obsidian-compatible
snapshots. It adds three-axis flat-end-mill CAM/stock-removal screening, declared
workholding/tool-change/carriage events, configurable Fanuc-style output, native
FDM G-code/3MF import, an external Bambu Studio CLI bridge and explicitly sourced
cost estimates. See [the contract and limitations](../MANUFACTURING_060C.md).

Manufacturing plans conditionally require document semantic format 53. Existing
documents retain their prior format. Source B-reps remain CAD authority;
simulation does not replace them. No full-machine/controller, exact target-gouge,
physical-process or production qualification is claimed.

## Verification record

Local Windows Release/MSVC builds and 14 distinct focused suites passed across
core/native, agent, persistence, source-graph, background-job and Studio checks.
The final manufacturing/UI suites were rerun after their last changes. Native
workspace and synthetic viewport captures were inspected. The external Bambu
Studio pilot sliced a source-derived solid with explicit snapshot profiles,
imported its 3MF G-code and exposed separately its declared 862-second / 5.39-g
estimate and unmodeled vendor-command diagnostics. A CNC pilot removed 1,200 mm3
at the declared voxel resolution and exported a checked NC file and a 12-node
Obsidian snapshot. These are bounded synthetic checks, not complete machine or
production qualification. Public evidence uses synthetic fixtures only; local
drawings, sessions, profiles and generated artifacts are excluded from commits.
