# 070A — Multicore scheduling and memory residency

Technical version **0.9.71**, phase **A**. Addresses
**A.02/A.04/B.01/B.02/D.02/F.05 — Verificado no escopo local**. Broader milestones
remain **Parcial**. No document semantic-format change.

## Changes

- A dirty dependency frontier replaces repeated whole-history scheduling scans.
  Completed work wakes actual consumers; published inputs use indexed lookup.
  Single dependent chains avoid worker handoffs and audited mesh workers avoid
  unrelated ancestor snapshots. Ordered publication and existing limits remain.
- MSVC x64 packed-position transforms use runtime-gated AVX2 with f64 arithmetic,
  scalar tails/fallback and no FMA contraction. Ordinary CPU work no longer
  holds the CUDA-resource mutex. The CUDA route still needs exact parity and a
  measured complete-transfer win; partial allocation failures release buffers.
- A bounded on-demand RAM LRU shares parsed native results only after full
  current-file authentication. Default retained allowance 256MiB/128entries;
  caller copies, transient parsing and worker allocations remain separately scoped.
- GPU display hits check exact source bytes before packing. Idle retention uses
  approximate adapter/free-memory telemetry up to256MiB by default, falls back to
  32MiB when unavailable, and releases idle buffers under pressure. Active handles
  remain protected. No VRAM preallocation or native B-rep GPU migration is claimed.
- Idle Windows connected MCP proxies exit after three seconds of confirmed
  endpoint absence. Standalone documents, memory hosts, busy/unknown endpoints
  and in-flight calls are preserved. Installer refusals identify executable/PID
  and background connections; the installer does not terminate active processes.

The scheduler tests passed 7,812checks covering serial/parallel geometry, cache
custody, limits, suppression, history order and rejection. Thirty terminal
native geometry-property comparisons matched in the dirty-branch measurement.
Current serial chain times4.718/4.669ms show that near-empty parallel scheduling
now stays close to serial overhead. This is not global thread coordination
across independently concurrent recomputes or Studio processes.

The CPU/VRAM policy suite passed 111checks including tails, unaligned arrays,
aliasing, concurrent outputs and memory-pressure policy. Disassembly of the
dedicated object contains vector double multiplies/adds and zero fused-multiply
instructions. A separate final compute benchmark measured CPU 1.224ms versus
CUDA 1.695ms including transfers; Auto correctly chose CPU. Both measured maximum
output errors were 0. CUDA remains available; forcing this particular operation
onto it would not improve the observed latency.

The RAM suite passed 130checks plus existing031B/032D cache regressions. One warm
parsed entry accounted for10,132,334bytes. Host private memory was12,996,608bytes
without retention and30,806,016bytes with retention; cumulative peak working set
29,487,104→44,777,472bytes. Worker processes are excluded from these host figures.
A 1 MiB pressure test retained 1,015,180bytes/10entries and evicted 31entries.
Malformed, removed, replaced and same-size/time corrupted disk files, oversized
results and caller mutation were checked.

Real OpenGL inspection reported a 268,435,456-byte idle allowance. A 36 MB display
buffer was retained and reused with zero additional packing/upload; forcing a
32MiB limit evicted it after release, while active references survived eviction.
The driver reported exact packed vertex-buffer size and the previous normal
quantization bound. Eight affected Studio suites passed with inspected scene,
realtime and viewport captures.
