# 032D — agent performance and assembly motion

This iteration builds on merged 031B. Runtime identity comes from
`release.json`; authored document versions remain independent. No private design
or agent session is a source fixture, public benchmark or distribution input.

Implementation must preserve exact producer authority, topology/reference custody,
explicit revisions, atomic publication, role ownership and unchanged production
tolerances. Focused remains default; Parallel remains optional. No provider
token/turn budgets are introduced.

The Windows LLVM/MinGW Release build with OCCT 8.0.1 passed **130/130 native
tests** (60.68 s) and **85/85 portable tests** (20.03 s), each with four CTest jobs.
These are suite execution durations, not CAD design or opening benchmarks.
Both Studio and MCP compile. The subsequent bounded cross-row scheduling change
passed its new dedicated test in both builds (0.08 s each), plus the native
evaluation-performance and engineering-agent regressions (1.24 s and 2.05 s).
The full suites were not repeated after that narrow change. These final checks
ran individually at below-normal priority with affinity limited to two logical
processors, after the earlier parallel builds/tests disrupted interactive use.
Hosted CI, another product's integration, live
provider token savings and manufacturing qualification are not established by
these local results.

The implementation and evidence are split by contract:

- [Compact responses and coordination](../AGENT_CONTRACTS_032D.md): revision-only
  status, reusable guides, changed preview/apply receipts, current native
  properties, selected assembly results, strict batch fields/allowlist and bounded
  owner-only idempotent reservation cleanup.
- [Preview custody](../PREVIEWS_032D.md): immutable owners, live-owner exclusion,
  budget recharging, transfer/snapshot materialization and retained validated
  frame/centroid caches. The 129 MiB synthetic allocation case caches a small
  independent leaf edit and publishes it without another geometry evaluation.
  Lazy native enrichment is promoted before compaction and survives commit.
- [Geometry storage](../GEOMETRY_STORAGE_032D.md): `NativePayload` packs float64
  positions and uint32 indices losslessly; `MeshSnapshot` shares immutable display
  buffers. The identical synthetic fixture's estimated owned allocation capacity
  fell from 5,329,329 to 337,521 bytes before optional JSON expansion. Two body
  copies use one native owner and one mesh owner. This is not process RSS.
- [Persistence](../PERSISTENCE_032D.md): resolved request identity survives changed
  scheduling/producer identity only through current exact native validation.
  Multi-input boolean cache requests bind every ordered input and retain the
  unchanged pairwise solver for misses; saved final results avoid rebuilding
  intermediate operations. Container SHA-256 matches the portable implementation;
  binary parsing avoids stringify/reparse without bypassing authoring gates.
- [Assembly motion](../ASSEMBLY_MOTION_032D.md): 2,465 portable and 2,567 native
  assertions cover skipped slots, nested parents, multiple joint carriers,
  source44/history, exact sampled copy clearance and bound cable recomputation.
- [Snapshots](../SNAPSHOTS_032D.md): native semantic face and synthetic pixel
  checks pass. Private front/isometric captures were visually inspected for body
  colors, cabling and emitted light. Steady emission, approximate transparency,
  unrendered textures/stamps and display-only authority are explicit.
- [Performance measurements](../PERFORMANCE_032D.md): matched public synthetic
  response-byte evidence remains separate from private project/cache-state
  measurements. A smaller response is not a measured provider token-saving claim.
  Explicit-input scheduling can cross owner-only rows while completed outputs
  retain their slot and allocation charge until ordered publication. Its dedicated
  parity/cache/rollback fixture passes; an opening speedup has not been measured.

The additional native snapshot suite passed 646 assertions. It proves one
decode/B-rep validity check per restored result, fresh unchanged exact metrics,
preserved mesh/topology, public unchecked-path rejection and strict aggregate
boolean envelopes. Numerical integration and Boolean tolerances are unchanged.

Initial verification found and corrected a real regression: dropping validated
reference caches caused new producer queries after prepared publication. The
original zero-additional-query assertion now passes. A separate custody check
found that legacy primitive native enrichment could be lost when compacting the
mutable body vector; promotion into a separate immutable owner now preserves it.
Early snapshot/motion fixtures also required an exact-native fixture, structural
JSON comparison and the actual exact-collision authority field. Their final
positive and negative assertions all pass; the final report does not omit these
failed attempts.

No private model, audit transcript, token record or benchmark artifact is committed
or packaged. Old unmatched opaque cache keys still need one reconstruction/save;
unsupported native operations replay normally. First-open validation, warm cache
loading and full reconstruction remain distinct workloads. Broader A.03/A.04,
B.04 and D.02/D.04 roadmap milestones remain **Parcial**.
