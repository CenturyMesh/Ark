# 066D — parametric programs, programs skill and Parametric designer role

Technical version: **0.9.67**. Focus: **D**. Milestones: **B.02, D.02, G.01**.
**Verificado no escopo local**; broader milestones remain **Parcial**.

- **B.02/G.01:** [parametric programs](../PARAMETRIC_PROGRAMS.md) let a design be
  written as bounded code (`ark.parametric-program.v1`): typed parameters, `let`,
  `set`, `for`, `if`, `assert`, `call` and `emit` templates.
  - A program compiles to native `feature.add`, `sketch.set`, `plane.set` and
    `material.set` under one namespace. It produces no geometry itself, and it
    runs no script, file or network operation.
  - The `parametric_program` tool validates, inspects and prepares one exact
    candidate for `doc_apply`. `expected_revision` and atomic publication are
    unchanged.
  - Re-runs replace only namespace-owned objects and reject local edits, outside
    dependants and stale sources.
- **D.02:** the `programs` onboarding topic is the skill agents load for this
  work. `AgentTeamDiscipline::ParametricDesigner` publishes only batches that carry
  a `program.*` operation. Studio offers it under **Agents** as an optional role in
  Focused and Parallel, within the eight-role limit. It is off by default.
- **Document format:** bindings use conditional semantic version **55**. Documents
  without a binding keep their earlier required version. The application now reads
  version 55 and rejects 56 as a future format.
- **Tools:** discovery lists 122 tools. The role sees 117 functions, or 43 after
  deferral, under the 128-function limit.
