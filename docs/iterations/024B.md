## Delivered source scope

- Single Assistant and team steering accept actual image content while a run is
  active, consume FIFO input at provider request boundaries and reject old writes
  at both worker and UI execution boundaries. An operation already executing is
  not forcefully interrupted. Final-response arrival and cancellation are tested
  separately; mock transport is not evidence of live provider completion.
- Stamps embed validated PNG/JPEG pixels and support bounded planar projection
  onto named exact planar or curved faces, or onto construction/sketch planes.
  Physical image dimensions can be expressions. Same-body face appearances and
  embedded textures are explicit source recipes with exact topology guards.
- Native split lines project one connected sketch wire onto a selected planar
  or cylindrical face, conserve the solid and publish exact region references.
  Unsupported or ambiguous projections reject rather than guessing geometry.
- `plane_authoring` creates/offsets named planes, moves a sketch to a plane and
  creates exact section contour or cut features from planes or sketch lines.
  Line-derived planes retain associative endpoint/axis references.
- `image_asset` and specialized `stamps`/`planes` onboarding expose the workflow
  to agents. Discovery contains 92 tools. A client-provided image-generation
  skill can supply an actual PNG/JPEG artifact; ARK imports it without claiming
  a built-in image-generation provider.

See [the scoped audit](AGENT_FEEDBACK_024B.md).

Stamps are display appearance, not engraving, exact raster reconstruction or
STEP texture export. Raster rendering supports them; the optional path tracer
reports its raster fallback. Software snapshots do not establish Studio stamp
fidelity. Section contours presently support one connected exact wire; general
multiloop contour authoring is not claimed. See [Stamps](../STAMPS_024B.md),
[split lines](../SPLIT_LINES_024B.md) and [planes](../PLANE_SECTIONS_024B.md).
