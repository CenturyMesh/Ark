# 080D — Multiple image references

Runtime **0.9.81**. **B.01/D.02 — Verificado no escopo local**.

Studio accepts a set of PNG and JPEG references from a single file selection
or shell drop. Additional selections append to the pending brief. Both authoring
modes send the ordered references together. Image to CAD shares one set of
rough overall dimensions across the references.

The native Windows Studio image-attachment test exercised preview navigation,
individual removal, append, invalid-batch rollback, multi-file drop and delivery
of two distinct images to one offline request. The rendered two-reference card,
mode controls and rough dimension fields were inspected. Connector tests used
synthetic PNG and JPEG inputs. The team tests checked the lead and assigned
specialist, and the Claude Code fixture inspected the ordered image blocks.

Twelve focused CTest checks passed on Windows with the patched OCCT SDK.
They covered release metadata, assistant connectors, ACP, Claude Code, agent
team, image attachment, two steering layouts, CAD import, baked playback,
drag-chain geometry and manual drag in Studio. Remote model interpretation
and reconstruction accuracy were outside the local verification scope.
