## Verification

Windows Release verification passed **15/15 native** and **12/12 portable-core**
CTest registrations. Both configurations pass 59 context-graph assertions and
397 team assertions. Tests cover unchanged reuse, deltas, invalid/stale/cross-scope
queries, reconstruction after saving/reopening, history attribution, capture
gaps, exact host-history preservation, pending-feedback protection and current
inspection before another write. Two distinct parallel roles reuse the same
host index; a peer commit invalidates the graph and the read-only reviewer
receives the changed dimensions. Existing authoring/BOM contracts, release
identity and synthetic OTA regressions also pass.

Studio, CLI, MCP and the OCCT worker compile. A separate real MCP subprocess
reports 034D / 0.9.35 and 97 tools, authors an isolated exact native box, reads its
parameter relationship, reuses the index and rejects a stale graph revision
without changing revision 1. No user design/session is an input to these checks.

The optional code wrapper passes **24 checks** covering pinned offline lookup,
source change/deletion, no-match status, owned paths, exclusive locking, CAD/env
exclusion, call-edge filtering and linked Markdown/canvas export. The actual
repository extraction produces **9,512 nodes / 30,332 edges** from 475 classified
code files and 479 allowlisted inputs. Eight files report parser errors/partial
extraction, 73 code files yield no symbols, and four copied configuration/CMake
inputs are unclassified. These counts overlap where the parser reports both
conditions. Current-source inspection remains required; this is not complete
C++ semantic analysis. The local export is checked against every canvas file
card; opening/rendering it in Obsidian was not tested.

The second fixture's complete provider request is 139,000 serialized bytes,
including schemas/instructions. The byte reduction in one component is not the
same percentage reduction in the whole request or in provider tokens. All these
checks use offline transports; no paid model calls or measured live cost/design
quality improvement are claimed. The [receipt](../verification-034D.json)
records source/artifact hashes, test registrations and limitations.

Initial attempts caught a missing activity-ledger include and an obsolete
read-batch fixture name. Harness corrections cover Windows stderr warnings,
UTF-8 source reads, absolute subprocess paths and build targets that are named
differently or unavailable in portable-core. Final results are after those
corrections; failed attempts are not counted as successful checks.

Re-exporting into one existing Obsidian vault initially left 74 canvas cards
without files after upstream pruning. Exporting a new graph into a separate
versioned directory and checking every file card before selecting it corrects
that observed case without deleting earlier exports or modifying Graphify.

The local launcher has the new runtime staged for the next start; the existing
Studio session remains open. Full suites, hosted CI, Linux execution, published
packages/OTA transport, live-provider savings and Obsidian UI acceptance remain
outside this verification.
