# 065F — unified Studio theme, line icons, right assistant dock and ARK Setup

Technical version: **0.9.66**. Focus: **F**. Milestones: **B.01, D.02, F.05**.
**Verificado no escopo local**; broader milestones remain **Parcial**.

- **F.05:** ARK Setup replaces the Inno Setup installer. It is a self-contained
  .NET 10 WPF single-file executable that carries the portable package as an
  appended payload. It installs by running the package's own `Install-ARK.ps1`,
  so the versioned layout remains the one ARK's in-app updater manages. Setup
  does not update ARK. It adds `uninstall.exe`, Start menu and Desktop shortcuts
  matching the former launcher shortcuts, and
  `HKCU\...\Uninstall\MeshSphere.ARK`. It takes over an existing Inno
  `MeshSphere.ARK_is1` folder and entry. Uninstall removes only Setup-owned and
  update-managed files. The window uses the graphite/orange palette over two
  layers rendered from the MeshSphere scene. The sphere drifts over a still plate
  (livelier while installing) and stays still when Windows animations are off.
  The self-contained runtime makes Setup about 161 MB, compared with about 83 MB
  for the last Inno build. See [Windows installer](../WINDOWS_INSTALLER.md).
- **F.05/B.01:** the startup panel shows a MeshSphere sphere render with the ARK
  wordmark. The splash thread decodes and scales both images before the panel
  appears; the main thread's startup work is unchanged. Provenance and hashes are
  in `assets/ui/README.md`.
- **B.01:** one palette (`src/view/ui_theme.inl`) derived from the 064A feature
  tree now covers the header, module tabs, ribbon, sidebar, viewport dock,
  dialogs, About and Win32 panels.
  - Model, Layers and Properties share a floating sidebar panel at 50% opacity.
  - Module tabs follow the authoring flow. Ribbon groups are shown as cards and
    ordered from setup/create to modify, combine, review and finish.
  - Every ribbon, header and viewport-dock command (196 actions) uses one
    outline-icon family from a shared kit, fitted to one optical size. No raster
    atlas icon remains in the ribbon. Long labels wrap to two lines instead of
    shrinking.
  - Feature-tree rows carry per-operation glyphs.
  - Scene overlays and handles stay neutral, so warm pixels in the viewport
    remain the selection halo.
- **D.02:** the assistant is a right-side dock with rail, normal, expanded and
  drag-resized widths. Readable reasoning appears per reply and per Parallel role.
  - Sources: Responses reasoning summaries, chat-completions
    `reasoning_content`, Messages/Claude Code thinking and ACP thought chunks.
  - Encrypted or redacted reasoning yields an explicit "not exposed" note.
    Reasoning is never added to copies, provider history or the document.
  - The Responses request asks for `reasoning.summary: "auto"` only on the
    official OpenAI endpoint, as described in [Assistant](../ASSISTANT.md).
    Defaults, tools, the Focused default and the absence of budgets are unchanged.

## Verification scope

The 064A stack was merged into `main` after full local CTest and the four
required hosted checks. The 065F branch was then verified locally on Windows
(MSVC 14.44, patched OCCT 8.0.1).

- **Native CTest on the integrated branch:** 179/179.
- **Studio UI suite (`-DARK_TEST_STUDIO_LIVE=ON`):** 78/82.
  - Three failures are unchanged from `main`: `studio-team-blockers-ui` and its
    compact variant ("Review blockers control missing"), and the
    `studio-parametric-graph-ui` stack overflow.
  - `studio-surface-edit-ui` failed once during the full run and passed 3/3 alone.
  - `studio-selection-glow-ui` exposed accent-coloured scene overlays. They
    were made neutral and the test passes.
- **New checks:**
  - `studio-chat-dock-ui`: rail, normal and expanded at 1280×800 and
    1920×1080, team roles, resize and settings round trip.
  - Offline reasoning-extraction tests for each provider shape.
  - The `--icon-sheet` review capture of all 196 command icons at 40 and 22 px.
  - Installer smoke tests: all pages, no clipping or overlap, motion range and
    live easing.
- **Startup timing:** six alternating launches compared the 064A runtime with
  this branch. Median time to a visible main window was 214 ms before and
  213 ms after. The splash appeared 25 ms later (53 ms), because it decodes its
  artwork before showing.
- **Installer:**
  - Isolated silent install, reinstall and uninstall into a temporary folder
    passed. The user-data sentinel survived, and the test uninstall key and
    folder were removed.
  - Migration was exercised only with a synthetic Inno entry.
  - A public Setup rejects the self-test screenshot mode, including when it is
    built right after a self-test build.
