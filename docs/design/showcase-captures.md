# README showcase captures

`docs/showcase-drone.png` is an unmodified viewport PNG captured from the owner's
open drone assembly on 2026-10-12, using Studio's `snapshot` tool with
`view: "viewport"`. The owner explicitly requested publication of this image.
It replaces the older drone-hull README illustration.

The capture contains only the CAD viewport, with its normal view controls. It
does not include account details, conversations or other desktop windows. The
editable drawing and private capture receipts remain outside the repository.
No image-generation model or geometry changes were used for this illustration.

Documentation/showcase scope: **F.03**. The image illustrates an existing design;
it is not evidence of new geometry, performance or manufacturing qualification.
