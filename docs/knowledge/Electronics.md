# Electronics and cables

Start with the board, connectors, required signal/power interfaces and available
space. An empty PCB outline or a connector envelope does not prove a circuit,
supplier match or electrical rating.

New smooth cables retain explicit `start`, ordered `waypoints` and `end`, with
`route_mode:spline`. A native 3D interpolating curve carries a circular sweep or
a rectangular `profile:{type:ribbon,width,thickness,up}`. Human Guide path handles
and agent edits change the same saved anchors. Legacy routes keep their original
derivation. New semantics conditionally require source45.

The control cage is immediate display evidence while a latest-generation worker
builds the exact candidate. A valid release publishes one current-revision edit.
Measure mouse handling separately from native sweep time; do not call GPU display
a GPU geometry solver. Too-sharp curves, invalid frames, self-interference and
declared-obstacle clashes require correction rather than hidden simplification.

Use `electronics_inspect` for native route/section/curvature evidence, then inspect
the exact B-rep. Connector/pin/net names are authored labels, not electrical
continuity or thermal qualification. Use [[ARK Knowledge/Vendors]] for verified
component sourcing, [[ARK Knowledge/Plastics]] for mounting/supports and
[[ARK Knowledge/Workflow]] for shared context and publication.
