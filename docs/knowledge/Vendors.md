# Approved Vendors and component evidence

Local source approval controls which public domains ARK may contact. Inspect
`library_vendors{operation:list}` to read the actual policy, site/API access and
adapter states. Approval does not prove product identity, license or procurement
qualification. Changing approval uses the policy revision, not the CAD revision.

Search the local library by known reference/dimensions first. For online sources,
search an approved catalog, read the exact product page, select an observed
resource link, fetch and validate actual STEP bytes, inspect body inventory and
then insert with current CAD `expected_revision`. Retain original bytes SHA256,
body selection and the observed retrieval receipt separately from declared
manufacturer/license information. A valid downloaded solid can still be the
wrong product. HTML/login/ZIP responses are not STEP.

MISUMI/TraceParts and other account catalogs may require browser access or an
authorized partner API. The listed API state is authoritative; a documented API
does not mean ARK has credentials or an active adapter. Browser logins stay in
the user's browser. Passwords, cookies, tokens and credential URLs must not be
copied into project notes, BOM or graphs.

Use [[ARK Knowledge/Electronics]] for PCB/cable interfaces,
[[ARK Knowledge/Plastics]] for supports, and [[ARK Knowledge/Workflow]] to keep
project context and source authority distinct.
