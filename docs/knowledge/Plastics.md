# Plastics

Describe the finished part naturally: hollow these walls, strengthen this face,
support this screw, locate this board, fit this lid or separate this part.
`agent_onboard{topic:plastics,detail:guide}` exposes the retained exact operations.
Inspect source faces and frames before using shell, draft or planar supports.

The Plastics workspace groups existing exact CAD capabilities with editable
recipes. It does not establish automatic mold parting, shut-off surfaces,
core/cavity generation, resin shrinkage or mold flow. Process targets require
explicit inputs and their own validation. A new menu is not process qualification.

Cable clearances and board mounts connect to [[ARK Knowledge/Electronics]].
Purchased hardware needs the workflow in [[ARK Knowledge/Vendors]]. Keep the
actual source/revision and unknowns recorded as in [[ARK Knowledge/Workflow]].
