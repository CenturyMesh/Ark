# Shared context and authority

`context_graph` retrieves a bounded neighborhood of saved project authoring.
035B adds authored cable endpoints/occurrence bindings, PCB component envelopes,
board-scoped net labels and supplier/source links. Stored retrieval evidence and
declared metadata remain attributed; the graph does not certify a supplier,
electrical continuity, full dependency closure or manufacturability.

Use the received project scope/fingerprints to omit unchanged facts. Read current
revision and selected exact geometry before writing. Parallel roles share the
host index; model conversations still pay input costs for the facts they read.
Keep Focused as the default, record failed attempts and never silently rebase.

Team progress is useful when a document, assignment, message or result changes.
037D retains successful static onboarding contracts when old tool receipts are
compacted for provider input. Complete guides and explicitly selected field
subsets remain distinct historical evidence. Reuse retained rules/examples;
their old example revisions never replace a current document inspection.
Studio writers receive the basic overview, sketch and native-solid contracts
before their first provider request. Specialist topics stay on demand. This
bootstrap is static documentation; current project facts still come from the
shared graph and revision-bound CAD inspections.
On an empty Studio document in Parallel mode, the lead first commits editable
geometry. Other writers' assignments and steering are retained until that
checkpoint; read-only review can run independently. Then Parallel proceeds,
with each released writer inspecting current revision before editing. Related
parameters, profiles, operations and placements may form one coherent atomic
batch instead of a provider round for each feature. A stopped unfinished lead
does not silently resume or imply completed design.
Repeated status reads are not design progress. After inspecting the current
revision, author a coherent editable checkpoint or deliver a concrete assignment
and let that turn finish. Use diagnostic metrics only to investigate a measured
problem; token/provider counters changing do not prove new geometry or evidence.

038B preserves mixed `query_batch` outcomes per query. Read `error_count` and
each row's `isError`: a missing projected field does not invalidate another
successful query. Reuse the returned `observed_result` and `available_fields`;
request only the exact needed recovery query when fresh evidence is required.
The coordinator retains the rejected query's identity, so unrelated successful
reads cannot conceal its failure. Historical recovery packets survive request
compaction without granting a current revision or write authority.
When a corrected selector succeeds for the same object, report both exact reads
through `team_report_task` with `state:in_progress`, `expected_revision` and
`read_resolutions`. The host verifies your later receipt and current project
revision before attributing the supersession. This records a corrected selection;
it does not claim the original query succeeded or waive write/completion checks.

Graphify indexes the repository code locally without a model backend. Curated
notes under `docs/knowledge` are copied into a separately versioned Obsidian vault,
with links to code notes when the exporter has actually produced those files.
No semantic extraction/upload is required. These are public product guides,
not imported user drawings, private sessions or an automatic cross-project brain.
Vault verification covers generated file hashes and file-link destinations.
An edited prior vault is preserved and exported separately before publishing a
new current pointer. Heading/block anchor existence is outside that check.

Start with [[ARK Knowledge/Electronics]], [[ARK Knowledge/Plastics]] or
[[ARK Knowledge/Vendors]] and retrieve only what the task needs.

## Persistent memory

039D adds semantic and literal recall over attributed decisions, failures and
episodes. Startup memory is untrusted historical data, separate from static
guidance. Inspect current source/revision before reuse. Promote useful scratch
episodes explicitly, retain contradictory evidence and use observed memory
revisions for maintenance. Source Graphify, live CAD context and Obsidian views
remain navigation layers; none replaces native geometric evidence.
